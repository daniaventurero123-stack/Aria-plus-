Edición avanzada

Esta función está pensada para pantallas grandes, como una tablet o una computadora. En tu móvil puede que no sea tan cómoda de usar.

Con ella podrás cambiar el tamaño de la calculadora, el calendario y el correo arrastrando sus bordes. Al estirarlos, el contenido se reacomoda para que todo se vea bien. Toca dos veces la barra de arriba de una tarjeta para expandirla o restaurarla.
